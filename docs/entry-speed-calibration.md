# 自動駕駛進站速度調校（2026-10-13）

目標：接近可穩定進站的速度，保留停靠前減速及原有離站設定。

用實際 Vehicle、收運狀態、車流、碰撞、路面及怒氣系統測試進站目標 8、12、14、16、18、19、20 km/h。每個速度跑五個情境：無車流基準、正常車流、兩組號誌時序加 6／12 秒收運等待，以及垃圾車延遲投擲；35 個情境皆完成三站，沒有車輛／建築物碰撞或車輪駛上人行道。

選用 19 km/h，低於既有 20 km/h 轉彎怒氣門檻，並預留控制器小幅速度誤差；不是宣稱物理模型的絕對極速。空路基準整段勤務由約 182.4 秒縮短至約 160.7 秒，包含相同收運作業，實際有車流時仍會讓車及等紅燈。

進站／離站速度分開設定：entrySpeedKmh=19、exitSpeedKmh=8。停靠前沿用距離限速，未完成工作及人員安全就位前維持停車。

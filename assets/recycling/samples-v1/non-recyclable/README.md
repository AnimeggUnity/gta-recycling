# 非回收物素材

使用內建 image_gen 逐張生成，沿用 ../prompts.json 的像素風格、配色、光源與透明背景；金屬罐原稿僅作風格參考。完整提示保存在 prompts.json。

馬桶蓋、枕頭、木頭、鞋子、後背包接入遊戲退回民眾分類；原 used-tissue PNG、WebP 與提示保留供未來使用。遊戲分類設定不代表地方回收政策。
